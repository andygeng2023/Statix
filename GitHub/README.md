# Statix

Production-oriented Streamlit stock research application.

## Local

1. Create `.streamlit/secrets.toml` from `.streamlit/secrets.toml.example`.
2. Create a virtual environment.
3. `pip install -r requirements.txt`
4. `python -m training.train`
5. `streamlit run app.py`

## Deployment

Deploy `app.py` from this repository on Streamlit Community Cloud. Put production secrets in the Cloud Secrets field, not GitHub. Use PostgreSQL for persistent multi-user data. The model artifact is generated by the training job. This release is designed so the trained `artifacts/model.joblib` can be committed to GitHub when it is small enough; otherwise store it in a trusted artifact store and adapt `src/models/model.py`. Never load untrusted model files.

Predictions are probabilistic model outputs and are not guarantees.
