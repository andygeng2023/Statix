# Statix

Production-oriented Streamlit stock research application.

## Local setup

1. Create `.streamlit/secrets.toml` from `.streamlit/secrets.toml.example`.
2. Create a Python 3.11–3.13 virtual environment.
3. `pip install -r requirements.txt`
4. Train once with `python -m training.train`.
5. Start with `streamlit run app.py`.

## Streamlit Community Cloud

Deploy `app.py` from GitHub. Do not commit `.streamlit/secrets.toml`; paste production secrets into the Streamlit Cloud Secrets setting. Use PostgreSQL when multiple authenticated users need durable shared storage. The model artifact is generated by the training command and is loaded read-only by the app.

## Model

The release uses a compact PatchTST-style patch-based temporal transformer trained globally across the configured stock universe. It predicts a five-class directional outlook plus a five-session expected return. A chronological holdout is used for validation. Reliability is deliberately conservative and is not a probability of correctness.

## Data

The default provider is Yahoo Finance through yfinance for prototype/development use. It does not guarantee exchange-grade real-time delivery. For commercial/high-frequency or large-universe deployment, replace the provider implementation with a licensed bulk/streaming provider without changing the UI/model interfaces.

Predictions are probabilistic research outputs, not guarantees or financial advice.
